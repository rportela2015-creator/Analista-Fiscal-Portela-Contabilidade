⚖️ Matriz de Divulgação Progressiva em 3 Níveis Operacionais

Clique nos botões do seletor no cabeçalho ou selecione os cartões abaixo para visualizar como a interface se adapta para cada perfil de usuário contábil:

1. Modo Gerencial CFO / Sócio
Decisão executiva rápida em < 5 segundos
  • 4 KPIs de Veredito Executivo
  • Semáforo consolidado de risco
  • 1 CTA Primário Único: "Autorizar Dossiê"
  • Zero fórmulas decimais abertas
  • Zero citações legais no fluxo principal
  • Expansão pontual de exceções via gaveta
2. Modo Operacional Padrão / Analista
Conferência diária de notas com máxima fluidez
  • Mini-KPIs compactos no topo
  • Tabela enxuta de 7 colunas prioritárias
  • Números com font-variant: tabular-nums
  • Sticky Action Bar fixa com CTA sólido
  • Gaveta lateral (ItemDetailDrawer) retrátil
  • Colunas secundárias ocultadas por padrão
3. Modo Sênior Perito / Auditor
Fundamentação jurídica e matemática exaustiva
  • Tudo do Modo Operacional ativo
  • Painel do Orquestrador DAG RFB expandido
  • Memória Base Dupla (Dec. 7.871/17) passo a passo
  • Créditos 3 Camadas Art. 47 LC 214/2025
  • Paridade RFB RTC centavo a centavo
  • Hash SHA-256 e blocos normativos abertos
